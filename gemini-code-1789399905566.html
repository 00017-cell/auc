เกณฑ์ปัจจุบัน τ = 0.5000 → คู่อันดับ (FPR, TPR) = (0.000, 0.000)

เส้นโค้ง ROC เกิดจากการนำ คู่อันดับ (FPR, TPR) ที่ระดับ Threshold ต่าง ๆ มาพล็อตลงบนแกนพิกัดฉาก โดยแกน X คือ FPR (อัตราผลบวกลวง) และแกน Y คือ TPR (อัตราผลบวกจริง หรือ Recall) คลิกที่แถวเพื่อเปลี่ยนเกณฑ์ไปยังจุดนั้น

FPR (แกน X): FP / (FP + TN) = สัดส่วนที่ทายว่าลาออกผิดจากคนที่ไม่ลาออกจริง
TPR / Recall (แกน Y): TP / (TP + FN) = สัดส่วนที่จับคนลาออกจริงได้ถูกต้อง
คู่อันดับพิกัด: (x, y) = (FPR, TPR) จุดบนระนาบ 2 มิติ (0,0) → (1,1)
