2. FPR (False Positive Rate / Fall-out) แกน X บนกราฟ ROC
FPR = FP FP + TN = 0 0 + 0 = 0 247 = 0.0000 (0.0%)
คำนวณสัดส่วนคนไม่ลาออกแต่โมเดลทายผิดว่าลาออก
3. คู่อันดับพิกัดฉาก 2 มิติ (FPR, TPR) พล็อตจุดบน ROC Curve
